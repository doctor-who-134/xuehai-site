版本记录

从 2.3 到 3.0，每一版写清改了什么、为什么改。数字用当次实测，不照抄历史记录。

3.0.0 2026-10-31 · 构建 35 当前版本

墨潮革命版 仅 macOS

四时世界 CWorld 由真实时间驱动：清晨 5–8、午后 8–17、黄昏 17–20、夜深其余。壳层换成 232 宽玻璃侧栏 + 14px 缝 + 24 圆角浮起纸页；⌘K 命令面板 13 个目的地。八景插画（晨潮、夜航、书山、灯塔、渡海、三道潮、芦苇、印）全部纯代码绘制，接入 12 屏；装饰性元素 ExcludeSemantics，删掉插画页面仍成立。

潮汐节拍只动 opacity 与 transform：enter 420ms、reveal 360ms（stagger 32ms×6）、numberRoll 620ms；减少动态时一步到位。六科 wash 只做背景面，一屏 ≤2 种、占屏 ≤12%。

当次实测：dart analyze lib 0 error / 0 warning；flutter test 632 通过（38 跳过 / 0 失败）；无头截图 108 张（26 屏 × 390/1280 × 日/夜 + shell 4 张）。

2.9.02026-10-31 · 构建 34

暖白赭陶

浅色段从冷纸换成暖白，强调色由天青改为赭陶，今日与练习的主行动卡改成「墨 → 赭」渐变。为什么：一天里会多次打开，冷白在灯下发蓝；暖白和赭陶更适合长时间阅读。

这一版的设计来自 Claude 的四轮改造提案，逐轮评审后只采纳能过令牌纪律与夜读对比的部分；夜读主行动卡按色板取渐变、渐变收进令牌、夜间强调改暖阶、令牌真源回填。

2.8.12026-10-31 · 构建 33

视觉收口

只修 QA 二轮出的三处视觉问题：标签在 Wrap 里被拉成整行、knowledge 首屏被读出上下两页、390 宽分段器裁掉「历」与「综」。另外给无头截图补了系统字体回退，截图里的中文不再画成方块。

为什么单独出一版：这三处在验收截图上直接露出来，改的是行与折行，不动结构；改完只重建 macOS 包，质量门不变。

2.8.02026-10-31 · 构建 32

设计语言 v2「纸墨潮汐」

全站视觉重做：一套纸墨令牌、一套 24 网格描边图标（子集 58 个、8.5KB）、一个目录式侧栏、一个编辑式今日页（桌面 8/4 双栏）、一套五态齐备的组件层；50 屏重排、列表去卡片化，所有可点元素补齐四态。为什么：这是「没有识别度、没有秩序」的问题，不是再加功能能解决的。

夜读在这一版第一次完整反相：白天墨底纸字，夜里纸底墨字，修掉主按钮在夜间退化成灰块的问题。632 测试全绿；26 屏 × 390/1280 × 日/夜的截图基线从这一版开始。

2.6.02026-10-27 · 构建 26

三态判分与不可变事件

判分从两态变三态：答对、答错、存疑。判不出的题不再算错，也不再进 BKT 与推荐；每次作答留一条不可变事件（来源、指纹、时间戳），本地追加、按账号隔离、可导出 JSONL。练习页显示状态与来源，解题页主观题标「待判定」，复习页不再静默失败。

为什么：2.5 及以前，主观题判不出会被写成 false，这条错数据一路喂给推荐，越算越偏。同一版还进了楷体（霞鹜文楷子集 2.05 MB，OFL）、8 款可绘制头像框、12 枚本机可算的勋章、学习记录 JSONL 导出。当次实测：analyze 0/0、460 测试全绿。

2.5.02026-10-25 · 构建 24

四端齐发

2.5 是最后一版同时出四端（macOS、Windows、安卓、iOS）的版本，也是拍照搜题、单词本、听力、函数图与引导页进入产品的一版。Windows 语音库由 CI 注入上游 x64 DLL。当次实测：analyze 0 error、411 测试绿；macOS 37M / Android arm64 51M / iOS 22M / Windows 28M。

为什么后面不出四端了：需要 Windows、安卓或 iOS 的，最近能拿到完整四端的就这一版；2.8 起只出 macOS，四端恢复出包需要明确要求。包仍在分发目录下，下载页有直链。

2.3.12026-10-24 · 构建 17

只出 macOS

修学海群反馈的六条（语文材料缺失标注、头像选图三态、宽屏版心、≥840 左侧栏、导航节流、我的思路拍照）与 2.3 核验五项（夜读恢复、点赞、申诉、判分存疑、框选），并加上内置更新通道。367 测试绿；产物 47 MB，本机换装。

2.3.02026-10-24 · 构建 16

四端交付

修 P0/P1 十条：举报中文化 + 重试、发帖附图、OCR 非题目粗筛、涂鸦擦笔、BKT 缓存作废、夜墨下架并迁移、取消语义；全站 33 处转圈归零、54 处失败文案改中文。310 测试绿；macOS 47M / Android arm64 50M / iOS 已签名 21M（描述文件 7 天）/ Windows x64 19M。
