安装

四个常见卡点

「已损坏，无法打开」

包未公证。右键 .dmg →「打开」，或在「隐私与安全性」里点「仍要打开」。

校验值对不上

先确认下载完整；不一致就别打开，重新下载再对一次。

iOS 装不上 / 七天后失效

本机是开发签名 ipa，描述文件 7 天到期；正式上架签名尚未办理。

找不到 Windows 版

Flutter 在 macOS 上产不出 Windows 可执行文件，需 Windows 机器或 CI；当前无公开包。
